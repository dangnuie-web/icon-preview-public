내 그림을 진짜 홈 화면에 깔아 보기 (시험 중)

이 기기의 브라우저에서 그림을 찾지 못했어요. 미리보기 화면으로 돌아가 그림 추가로 다시 넣어 주세요. (그림은 넣은 기기·브라우저에만 남아요)

앱 이름

아직 확인하지 못한 기능이에요. 아이폰은 홈 화면 아이콘을 보통 서버에 있는 그림 파일 주소로 읽어요. 이 그림은 서버에 없고 이 기기 안에만 있어서, 아이폰이 받아 주지 않으면 아이콘 대신 이 페이지를 찍은 모양이 깔려요. 그래도 예시 아이콘은 진짜로 깔아 볼 수 있어요.

  1. 1이 페이지를 아이폰 사파리에서 연다 (카톡 안의 브라우저면 오른쪽 아래 사파리 버튼으로 나간다)
  2. 2화면 아래 가운데의 공유 버튼(네모에서 화살표가 올라오는 모양)을 누른다
  3. 3목록을 내려 "홈 화면에 추가"를 누른다
  4. 4이름을 확인하고 오른쪽 위 "추가"
  5. 5홈 화면 맨 뒤 페이지에 생긴 아이콘을 본다. 다 봤으면 길게 눌러 "북마크 삭제"
